# Contributing

This repository is not accepting outside contributions.

The code is published for reference under an all-rights-reserved license (see
`LICENSE`). Pull requests from anyone who is not an invited collaborator will
be closed without review, and issues are disabled.

If you have been added as a collaborator: work on a branch, open a pull
request, and wait for the required checks to pass. Direct pushes to `main` are
blocked for everyone, including the repository owner.
